# RAHSM 公式复现与验证说明

本实现将 CHP、KHN、PTS 接入现有 TransReID 训练框架。实现状态为论文公式复现与程序验证，性能结论需通过后续正式实验获得。

## 文件与入口

| 文件 | 内容 |
|---|---|
| `metaeye/rahsm.py` | 共享标签关联、CHP、KHN、PTS、角色感知 InfoNCE 和模态均值更新 |
| `metaeye/training.py` | 前 30 轮单模态训练，随后切换至共享伪标签与 RAHSM 损失 |
| `configs/rahsm_regdb_laptop.json` | RAHSM 配置，λ₀=0.3、K₁=16、K₂=1、τ=0.05 |
| `configs/regdb_laptop.json` | 原 ADCA + TransReID 配置，供基础版使用 |
| `scripts/verify_rahsm.py` | 独立公式计算、梯度及合成张量的入口检查 |
| `docs/rahsm_verification.json` | 组件验证摘要、源码校验值与验证范围 |

本机原始验证输出保存在 `rahsm_verification.txt`，该日志未纳入公开仓库。运行下列验证命令可查看当前环境的实际输出。

在项目根目录执行验证。

```powershell
.\.venv\Scripts\python.exe scripts\verify_rahsm.py
.\.venv\Scripts\python.exe scripts\verify_core.py
```

验证使用二维数值示例、临时目录里的小线性层及随机合成图像。真实 TransReID 检查只做前向与反向传播，核对梯度及参数保持情况。合成入口检查替换了图像加载、特征提取和聚类输入，检查阶段切换与文件留存。正式 RegDB 图片及预训练 ReID 权重不参与这些检查。

以后训练 RAHSM 时，入口为 `main.py train --config configs/rahsm_regdb_laptop.json`。默认保存到独立目录 `runs/rahsm_regdb_trial1_seed1`。本次实现与验证过程未执行这条正式训练命令。

## 公式与实现对应

| 原文依据 | 代码中的计算 |
|---|---|
| 式（1）—（2） | 共享身份在可见光、红外中的特征算术均值，保存为两个模态中心。 |
| 式（3）—（4） | 每个批次按身份和模态求查询均值，再进行一次动量更新。更新在有效优化器步骤后执行。 |
| 式（5）—（6） | `p_hat = p + λ × (p - p_other)`，对两个模态对称外推。 |
| 式（7）—（8） | 验证中点保持不变，跨模态中心差放大为原来的 `1 + 2λ` 倍。 |
| 式（9） | 每个身份、每个模态独立 K-means。对每个子簇寻找最近的异身份中心，用 `u_hat = u + λ × (p_neighbor - p_owner)` 生成候选。 |
| 式（10） | `λ = λ₀ × log(1 + (e - 1) × t/T)`。PTS 关闭时使用常数 λ₀。 |
| 式（11） | 目标身份的两个 CHP 候选按欧氏距离选最远者，其他每个身份的 KHN 候选分别选最近者。 |
| 式（12） | 每个查询得到一个正原型与每个异身份的一个负原型，按点积和 τ 计算交叉熵形式的 InfoNCE。 |

查询来自现有归一化编码器。模态中心使用原始均值，外推后的候选保持原始数值，从而保留式（7）—（8）的几何关系。中心和子簇作为停止梯度的记忆表示，梯度通过查询回传至编码器。

## 共享标签

RAHSM 原文第 2.2 节说明使用基于 SDCL 的深层特征跨模态排序关联。当前实现参考固定版本 SDCL 的 RegDB 代码，采用以下深层特征归约。

1. 每张可见光训练图选最相似的 10 张红外图，对其红外伪标签投票。
2. 用可见光内的 5 个近邻对转移标签作局部投票平滑。
3. 保留在两个模态都存在的身份，重新编号为连续共享标签。
4. 原 DBSCAN 离群点保持排除。有效共享身份不足两个时明确报错。

以上处理仅使用编码器特征和聚类伪标签。当前基础版 ADCA 的 CMA 保持原实现，RAHSM 跨模态阶段使用共享标签和 RACL 损失。

## 原文未完整规定的实现选择

下列选择已落实在代码和配置中，后续如取得作者实现可逐项核对。

- **排序参数与平局。** RAHSM 未给出完整的深层排序实现。10 个跨模态近邻、5 个同模态近邻取自 SDCL；当前投票同票时优先距离更近者，并排除原始离群点。完整 SDCL 同时使用浅层与深层特征。
- **KHN 的中心集合。** 按第 1.3 节“当前身份在对应模态下的中心”和式（9）实现，在对应模态的异身份中心中搜索方向。论文第 2.5 节另有“跨模态近邻”描述，完整搜索域仍需作者代码进一步确认。
- **K₁ 大于可用样本数。** 使用 `min(K₁, 不同特征数量)`。RegDB 每个真实身份每模态仅 10 张图，无法对少于 16 个样本直接进行 16 类 K-means。逐模态、逐共享身份的实际 K 值保存在 `subcluster_counts`。
- **K₂ 大于 1。** 每个近邻身份生成一个候选，再按式（11）选择。论文仅写出 K₂=1 的公式，默认配置使用该设置。
- **λ 的计时范围。** 从跨模态阶段第一步到最后一步计算 t/T。默认前 30 轮不引入难样本，后 20 轮的最后一步到达 λ₀。原文未明确 T 是否包含前期单模态更新。
- **动量及归一化。** μ 沿用已有配置 0.2。原文给出 μ 的含义，未提供其数值；模态中心和生成候选按公式保持未额外归一化。
- **损失组织。** 跨模态阶段使用式（12），保持已有可见光增强双视图与红外两路损失相加的组织方式。原文未给出额外的总损失权重。
- **算力与骨干设置。** 沿用本机小批量、AMP、梯度检查点，以及现有全局 TransReID 和 ImageNet 初始化。原论文的双 RTX 3090、每模态 8×16 批量与本机设置有差异。

## 模块开关与后续对照

`rahsm.chp`、`rahsm.khn`、`rahsm.pts` 可独立开关。命令行也支持 `--disable-chp`、`--disable-khn`、`--disable-pts`，仅对 RAHSM 配置生效。

CHP 关闭时，正样本使用查询对应模态的身份中心；KHN 关闭时，负样本使用该模态的其他身份中心。两者都关闭时退化为共享标签下的普通原型对比损失。PTS 关闭时，启用的困难样本模块使用常数 λ₀。

后续做模块归因时，应固定 RAHSM 共享标签策略、数据划分和训练设置，再切换上述开关。原 ADCA + TransReID 配置与 RAHSM 配置的跨模态关联方式不同，对比时应说明这一条件。

## 自动保存的 RAHSM 材料

跨模态阶段的每轮归档增加以下文件。

- `shared_label_association.json` 与 `shared_labels.npz` 保存关联设置、共享编号与原红外伪标签的对应及逐图共享标签。
- `rahsm_initial_bank.npz` 保存模态身份中心、子簇中心、所属身份/模态、候选槽位和实际 K 值。
- `steps.jsonl` 增加 `rahsm_active` 和实际 λ，可用于绘制 PTS 曲线。
- `rahsm_last_batch_roles.npz` 保存该轮最后一批的查询特征、共享标签、最远正样本模态、各身份最近负样本槽位、近邻身份，以及更新前的中心。
- `rahsm_final_centers.npz` 保存本轮批均值动量更新后的身份中心。

每轮开始时根据更新后的编码器特征重建共享标签和候选集合，断点恢复从已保存的下一轮继续。既有基础版断点仍按基础版配置恢复，跨方法或开关不一致的恢复会报错。
